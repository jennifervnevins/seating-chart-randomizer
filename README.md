# Classroom Seating Randomizer

This is a simple cross-platform seating chart app. It runs in a web browser, so it works on both Mac and Windows without installing a special desktop program.

## How to Open It

Open `index.html` in Chrome, Edge, Safari, or Firefox.

## What It Can Do

- Start with student cards numbered 1-20, then add or edit numbers as needed.
- Use six class tabs to keep separate seating charts for different classes.
- Paste a whole class list, one item per line.
- Randomize only the currently selected class seating chart with one button.
- Choose rows, pairs, trios, groups, U-shape, center aisle, or freeform arrangements.
- Drag desks around by hand with the mouse pointer.
- Edit the number directly on a desk.
- Change the number, spacing, and size of desks.
- Save automatically on the same computer.
- Export a JSON file to move a seating chart to another computer.
- Import a saved JSON seating chart.
- Print the chart.

## Moving Between Mac and Windows

Use **Export** to download a `.json` seating chart file. Move that file to the other computer, open `index.html` there, and use **Import**.
